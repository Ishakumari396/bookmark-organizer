# 📌 Bookmark Saver

A simple and responsive bookmark management web application built using HTML, CSS, and JavaScript.
This project allows users to save, organize, and manage their favorite links in one place without any backend.

## 🚀 Features

- Add new bookmarks (Website Name + URL)
- Delete saved bookmarks
- Open saved links in a new tab
- Responsive and clean user interface
- Stores data using Browser Local Storage
- Fully client-side application

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Browser Local Storage API

## 💡 How It Works

1. The user enters a website name and a valid URL (e.g., https://example.com).
2. The application validates the input to ensure the URL format is correct.
3. Once validated, the bookmark data is stored in the browser using Local Storage.
4. The saved bookmarks are dynamically displayed on the page.
5. Each bookmark can be opened in a new tab or removed when no longer needed.
